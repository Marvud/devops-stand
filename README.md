# DevOps Stand

Учебный проект для перехода из поддержки в DevOps.

## Цель
Подготовиться к позиции Junior DevOps и собрать практический проект для резюме.

## Окружение
- Workstation: macOS, zsh
- Target: Rocky Linux VM
- Access: SSH

## Направления
- Linux administration
- Bash automation
- Docker
- Monitoring
- CI/CD
- Documentation
